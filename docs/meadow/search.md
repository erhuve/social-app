# Meadow search help

Meadow uses the selected AppView's search service. Common filters include:

- `from:handle.example` to search posts from an account
- `to:handle.example` to search replies to an account
- `mentions:handle.example` to search mentions of an account
- `lang:en` to filter by language
- `since:2026-01-01` and `until:2026-02-01` to limit dates
- `domain:example.com` to filter links by domain
- Quotation marks to search for an exact phrase

Filters can be combined with ordinary search terms. Availability and results are
controlled by the AppView providing search.
